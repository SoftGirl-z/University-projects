# 💞 Foster Family & Sponsorship Program
### *Final Year Project – Eastern Mediterranean University*

This project introduces a **digital platform for child sponsorship and foster care management**, designed to connect **donors, families, and organizations** that support children in need.  
It consists of both **mobile and web-based applications**, built with a focus on usability, scalability, and data integrity.

---

## 🧠 Project Overview

The **Foster Family Program** facilitates sponsorship and adoption-related processes through a transparent digital interface.  
It allows users to sponsor a child, make donations, and track impact reports securely and efficiently.

The system is developed to:  
- Simplify the process of child sponsorship.  
- Digitize the management system for NGOs and foster institutions.  
- Increase transparency and trust through data-driven reporting.  

---

## 🧩 Key Features

- 👨‍👩‍👧 **Foster Family Registration:** Families can register and apply to sponsor a child.  
- 🧒 **Child Profiles:** Each child has a unique digital profile including background, education, and health information.  
- 💳 **Donation Management:** Integrated system for financial and material donations.  
- 📊 **Admin Dashboard:** Manage sponsors, children, and track donation histories.  
- 📱 **Mobile Compatibility:** Fully responsive web and Android app versions.  
- 🔒 **Secure Data Handling:** All user and donation data is encrypted.  
- 📬 **Notification System:** Email and in-app notifications for updates.

## 🧮 System Architecture

The system consists of two main layers:  

1️⃣ **Web & Mobile Frontend:**  
   - Displays data and manages user interaction.  
   - Responsive design for accessibility.  

2️⃣ **Backend (API Layer):**  
   - Handles user authentication, data validation, and CRUD operations.  
   - RESTful endpoints for sponsor and child management.  

3️⃣ **Database:**  
   - Stores structured data in MongoDB for fast and scalable access.

## 🧮 Non-Functional Requirements

- **Security:** Uses SSL and token-based authentication.  
- **Usability:** Simple, multilingual interface.  
- **Performance:** Optimized API calls and real-time updates.  
- **Scalability:** Supports multiple NGOs and thousands of records.  
- **Maintainability:** Modular, microservice-friendly structure.
